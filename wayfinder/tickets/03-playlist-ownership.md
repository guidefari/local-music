# Choose the playlist source of truth

## Question

Should locally curated playlists be stored in an app-managed library with export, kept directly as portable playlist files, or follow another model? Compare editing, portability, path changes, metadata, and the later need to import streaming playlists and prepare Rekordbox sets. Decide only after the first journey and file ownership are clear.
